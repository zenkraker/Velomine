# RecordPhone

Record: start a ride on the phone, and the rides saved on it. Route `/record`, `features/recording/recording_screen.dart`. Phone only; the web has no recorder.

- One big Start button, the ride type, auto-pause and the heart-rate strap ([pairing](StrapPairingSheet.html)). Recording settings are in the `⋯` menu ([Recording settings](RecorderSettingsSheet.html)).
- "On this phone" lists the rides recorded here with their upload state; each row's menu holds Retry, Upload and Delete from the phone.
