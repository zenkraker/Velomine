# EventsPage

Events: the rider's races and sportives. Route `/progress/events`, opened from Goals, `features/progress/events_screen.dart`.

- Add an event is the page's one action (a form sheet: name, kind, date, distance, climbing, notes).
- The next event leads with its days to go; every event's menu holds Edit, Link a ride / Unlink and Delete.
- A past event links the ride that was it when it is the rider's only ride that day.
