# NearbyClubsPage

Clubs near you: discoverable clubs on this server, nearest first. Route `/clubs`, `features/club/nearby_clubs_screen.dart`.

- The rider's position (asked once, never stored) or a saved location sorts the clubs; the radius chips widen the search.
- Ask to join opens a sheet with an optional word for the owner. One open request at a time; the requested club shows "Requested".
