Status

What works today.

Velomine is in early development. This page tracks the v1 goal and the features that are actually implemented, not the ones that are planned.

The v1 goal

Ride, record, share.

Make Velomine usable on its own: record with the phone or upload any FIT file, see every ride, check in daily, and share safely.

Cloud and enrollment

In progress

One app and one database for every club, with each club’s data kept apart; a self-hosted club runs the same thing with one club. Clubs, members and coach sharing work today; enrolling a new club is still done with me personally. Missing:

  • database access rules that keep each club’s rows apart as a second line of defence
  • creating the club and its first admin when it enrolls
  • the plan agreement and the first invoice
  • the first import and the go-live checklist

Server core

In progress

Accounts, roles, single sign-on, admin approval, password reset, optional two-factor sign-in and the device list work. API keys are next.

Ride files

Done

FIT, GPX and TCX files read in the background into a ride.

Rides

In progress

Maps, charts, every stream, heart-rate and power zones, IF, TSS, TRIMP and laps. Photos, thumbnails and reverse geocoding are next.

Bikes

Done

Bikes, wheel circumference, parts, wear by distance, hours or months, and a default bike.

Mobile app

In progress

Android records with the screen off, a heart-rate strap, auto-pause and background upload. Speed, cadence and power sensors are being integrated; iOS is next.

Web app

Current features

What is in the app.

Everything below is implemented and usable today. The next section lists what is not.

Accounts and access

  • Sign-up with club admin approval
  • Password sign-in, with a cookie on the web and a refresh token on the phone
  • Single sign-on with the club’s existing provider
  • Password reset by email, or a one-time link from a club admin
  • Optional two-factor sign-in with an authenticator app and single-use recovery codes
  • A device list: see every signed-in phone and browser, sign one out, or all the others
  • Club admin, member and coach roles
  • Lock or delete an account; deleting removes every ride and file
  • Profile: FTP, weight, maximum heart rate, time zone and week start
  • Download every ride and file as a ZIP

Rides and analysis

  • FIT, GPX and TCX uploads, including gzipped files
  • Distance, moving time, climbing, speed, power, normalized power, heart rate and cadence
  • Route map and a chart for every signal
  • Heart-rate and power zones, IF, TSS and TRIMP
  • Laps read from FIT and TCX, with numbers recomputed from the samples
  • A bike picker on every ride

Training and goals

  • Weekly, monthly and yearly totals
  • Goals per week, month or year: distance, climbing, riding time or number of rides
  • A 30, 90 and 365-day dashboard with daily load, fitness, fatigue and form
  • A power curve with FTP and VO2max estimates

Wellbeing

  • Daily check-in: fatigue, soreness, mood, stress and motivation
  • Consent before the first check-in, asked again when the terms change
  • RPE and notes on each ride; notes stay private
  • A readiness view from form, recent load and the check-in
  • Coaches see shared scores and RPE, never the notes

Bikes and components

  • Bikes with wheel circumference and the distance a used bike already had
  • Parts with limits by distance, riding hours or months
  • A wear bar on every part and a replace action
  • A default bike for new rides

Clubs and sharing

  • Clubs, membership and joining with a code
  • Sharing rides, analytics, the route of a ride and wellbeing with coaches
  • Wellbeing only with explicit consent; notes stay private
  • Every choice is revocable
  • Read-only coach views and a record of who looked
  • Privacy zones around saved places, start and end trimming, and per-stream switches on everything a coach sees

Phone recorder

  • Android recording with the screen off
  • Standard Bluetooth LE heart-rate strap, paired once and reconnecting for later rides
  • Raw samples kept on the phone, assembled into a FIT file when you stop
  • Auto-pause, automatic upload and retries, even when the app is closed

Club admin and server

  • Every account, roles, lock, delete and club admin approval
  • Sign-up, club admin approval and map settings
  • In-app notifications, and optional email
  • Day and night themes, English and Italian
